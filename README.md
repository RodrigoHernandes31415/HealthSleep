# 📊 Health & Sleep Lifestyle Analysis

Este projeto realiza uma análise exploratória de dados (EDA) e tratamento de variáveis relacionando hábitos de vida, saúde física e métricas de sono.

## 🎯 Objetivos do Projeto
- Tratar e limpar variáveis numéricas e categóricas (como separação da pressão arterial em Sistólica e Diastólica).
- Categorizar faixas etárias para entender padrões de sono em diferentes grupos de idade.
- Analisar a correlação entre categoria de IMC (BMI), níveis de estresse e distúrbios do sono.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Pandas** (manipulação e limpeza de dados)
- **NumPy** (operações numéricas)
- **Matplotlib & Seaborn** (visualização de dados)
- **Jupyter Notebook**

## 📂 Arquivos no Repositório
- `analysis.ipynb`: Notebook com o passo a passo da limpeza e análise dos dados.
- `Sleep_health_and_lifestyle_dataset.csv`: Dataset com as informações de saúde e sono.
